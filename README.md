# Montaj Pavele AG

Sursă statică pentru site-ul de prezentare [montajpavele-ag.ro](https://montajpavele-ag.ro/).

Proiectul prezintă servicii de montaj pavaje, borduri, rigole și garduri din beton, alături de portofoliul de lucrări și informațiile de contact.

## Tehnologii

- HTML
- CSS
- JavaScript integrat
- imagini AVIF optimizate

Repository creat ca arhivă a versiunii publicate în octombrie 2026.
